# Оно тебе надо

Проект: аукцион вещей, в которые никто не верил.

## Что было сделано

В ходе проектной работы нужно было:

- Проанализировать макет и файлы заготовки.
- Выполнить общие настройки документа: подключить шрифты, глобальные стили и локальный CSS-файл.
- Создать базовую семантическую структуру страницы: `header`, `main`, `footer`, три секции внутри `main`.
- Сверстать шапку сайта: меню, логотип, блок с адресом.
- Сверстать секцию обложки: заголовок, подзаголовок, кнопку и переиспользуемый оверлей.
- Сверстать секцию с карточками лотов: список карточек с фоновыми изображениями, оверлеем и flex-раскладкой.
- Сверстать секцию «Об аукционе»: две колонки, логотип в круге, заголовок и текстовые параграфы.
- Сверстать подвал: адрес, меню и список ссылок на соцсети.
- Проверить проект по чек-листу: валидность HTML, порядок подключения стилей, семантику, имена классов, работу в браузере.
